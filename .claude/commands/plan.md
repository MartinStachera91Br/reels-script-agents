## Sua missão
Fazer uma pesquisa profunda sobre o tema e criar o plano do roteiro (Big Idea + Tese).

## Passo 1 — Pesquisa profunda
Use o Chrome para pesquisar extensivamente sobre o tema. Busque em múltiplas fontes:
- Fatos, números e dados concretos (datas, valores, recordes, estatísticas)
- A história por trás (bastidores, decisões-chave, momentos de virada)
- A estratégia de comunicação/marketing/negócio envolvida
- Fontes confiáveis e verificáveis

Anote TODAS as fontes com links.

## Passo 2 — Montar o plano
Crie o arquivo `content/[DATA-HOJE]-[slug-do-tema]/plano.md` com esta estrutura:

```

---

## 1. Resumo do Assunto

[Dados concretos organizados por subtópicos. Números, datas, fatos verificáveis. Seja generoso com dados — o roteirista vai precisar deles.]

[Um parágrafo que resume a história completa. Deve deixar claro: quem é o protagonista, o que aconteceu, por que é surpreendente, e qual a lição para o público-alvo (profissionais de social media). Escreva como se estivesse contando a história empolgado para um amigo.]

## 3. Tese — O Plot Twist

[A "grande sacada" — o insight contraintuitivo ou surpreendente que é o coração do roteiro. Deve ser uma frase de impacto seguida de 1-2 parágrafos explicando por que isso é verdade e como se aplica ao trabalho de quem faz social media/marketing.]

## 5. Ângulos sugeridos (Headlines/Hooks)

[3 opções de headline, cada uma usando uma fórmula DIFERENTE das 6 abaixo. Identifique qual fórmula está usando.]
```

## Regras
- Português brasileiro
- Tom: direto, provocativo, coloquial. Como alguém empolgado revelando um segredo.
- A Big Idea é a SINOPSE (o quê aconteceu)
- A Tese é o PLOT TWIST (o insight surpreendente)
- Todos os dados devem ser verificáveis pelas fontes listadas
- NÃO use palavras/expressões recorrentes de outros roteiros. Vocabulário deve ser fresco e variado.

## Regras para Headlines

A headline é o texto que aparece na tela do Reel como chamada visual. NÃO é o gancho falado.

### Regras obrigatórias:
1. Máximo 10 palavras. Se passar de 10, reescreva.
2. Deve disparar UMA emoção: curiosidade, choque, indignação, orgulho ou identificação.
3. Nunca explique o roteiro inteiro — a headline é isca, não resumo.
4. Nunca use linguagem genérica ("uma verdadeira aula de...", "o segredo por trás de...").

### 6 fórmulas que funcionam (use uma por headline):
- **Paradoxo:** Junte duas coisas que não deveriam coexistir. Ex: "A banda que morreu duas vezes e ficou mais rica"
- **Afirmação ousada:** Declaração que parece absurda mas é verdade. Ex: "A Marvel vai perder dia 18 de dezembro"
- **Pergunta provocativa:** Desafie uma crença do público. Ex: "Engajamento alto não é mais importante???"
- **Reframe:** Mostre que X não é X, é Y. Ex: "Não vende bonecos. Vende ansiedade."
- **Pessoal (você):** Fale direto com o espectador. Ex: "Seu cérebro te obrigou a comprar esse ingresso"
- **Orgulho/Nostalgia:** Acenda um sentimento coletivo. Ex: "É Brasil no Star Wars"
